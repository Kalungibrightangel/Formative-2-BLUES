Low-Level Programming

Learn how computers work beneath the surface - from memory and processors to the operating systems that manage them. This path suits students who enjoy precision, performance and understanding exactly what their code is doing.

Core Courses

  • C and C++ Programming
  • Operating Systems
  • Computer Architecture & Memory Management
  • Embedded Systems

Career Paths

Systems Engineer Firmware Developer Embedded Software Engineer Performance Engineer

AR/VR

Create interactive and immersive digital experiences that blend the real and virtual worlds. This path suits students who enjoy 3D design, spatial thinking and building experiences people can step into.

Core Courses

  • 3D Development & Game Engines
  • Virtual Reality Design
  • Augmented Reality Development
  • Human-Computer Interaction

Career Paths

AR/VR Developer Game Developer 3D Interaction Designer Simulation Engineer

Full-Stack Development

Build complete web applications from front-end to back-end. This path suits students who like seeing a project come together end-to-end, from what users see to how their data is stored and served.

Core Courses

  • HTML, CSS and JavaScript
  • Backend Development & APIs
  • Databases
  • Cloud Deployment

Career Paths

Full-Stack Developer Front-End Engineer Back-End Engineer Product Engineer
