## Project Overview

This project demonstrates the setup, configuration, testing, and troubleshooting of a basic web infrastructure using Linux.

## Technologies Used

* Linux
* SSH & SSH Key Authentication
* NGINX Web Server
* HTTP & Raw HTTP
* Telnet
* cURL
* REST API
* SCP & SFTP

## What We Implemented

* Configured the Linux environment and user accounts.
* Set up SSH and key-based authentication.
* Configured NGINX to host a website.
* Tested HTTP methods and status codes.
* Used Telnet to examine raw HTTP communication.
* Interacted with a public REST API using cURL.
* Performed file transfers using SCP and SFTP.
* Deliberately created and resolved an NGINX service failure.

This repository contains the website files, configuration files, practical documentation, and evidence for the Web Infrastructure Formative 2 assessment.
